A program that writes the one note a smart fridge leaves on its door screen for its owner.

> The yogurt expired on Monday. I kept it anyway, because unlike you, I commit.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (one line, under the 200-character cap).
